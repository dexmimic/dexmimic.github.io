# DexMimic

Anonymous project page for DexMimic.

## Structure

- `index.html`: title, appendix link, teaser, abstract, and method overview.
- `static/assets/`: supplemental PDF and paper figures.
- `static/css/style.css`: responsive page styles.

## Preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. GitHub Pages serves the `main` branch from the repository root.
